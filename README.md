# Hands-on Git

A simple project created as part of the "Introduction to Git and GitHub" hands-on lab. This repository demonstrates core GitHub repository setup practices, including licensing, contribution guidelines, and a basic shell script.

## Description

This repository was built to practice:
- Creating and structuring a GitHub repository
- Adding standard open-source files (LICENSE, CODE_OF_CONDUCT, CONTRIBUTING)
- Writing and committing a simple Bash script

## Contents

- `LICENSE` — Apache License 2.0
- `CODE_OF_CONDUCT.md` — Community guidelines for contributors
- `CONTRIBUTING.md` — Instructions for contributing to this project
- `simple-interest.sh` — A Bash script that calculates simple interest

## Simple Interest Script

The `simple-interest.sh` script calculates simple interest based on user input.

### Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

You will be prompted to enter:
1. Principal amount
2. Rate of interest
3. Time period (in years)

The script then outputs the calculated simple interest.
